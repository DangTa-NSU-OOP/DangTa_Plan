# 01. 서비스 기획 — 당타(DangTa)

## 1. 한 줄 소개

> **당타** = 우리 학교 안에서만 이루어지는 중고거래 · 중고책 · 소모임 · 커뮤니티 웹앱
> 당근마켓의 "동네" 대신 "캠퍼스"를, 에브리타임의 "학교 인증"과 "학업 도구"를 결합했다.

---

## 2. 배경 및 문제 정의

### 2.1 현재 대학생이 겪는 문제

| # | 문제 | 현재 대안 | 한계 |
|---|------|-----------|------|
| P1 | 캠퍼스 안에서 물건을 사고팔 곳이 마땅치 않음 | 당근마켓, 에타 장터게시판 | 당근은 동네 기준이라 학교 밖 사람과 매칭 / 에타 장터는 검색·사진·채팅이 빈약 |
| P2 | 전공 교재를 정가로 사기 부담, 선배 책 구하기 어려움 | 중고서점, 에타 book | 강의명·교수명 기준 탐색 불가, 재고·상태 확인 어려움 |
| P3 | 관심사 기반 소모임을 찾고 만들 통로가 분산 | 에타 소모임, 오픈채팅, 학과 단톡 | 신뢰 낮음(외부인 유입), 운영 도구 없음 |
| P4 | 학교 이야기를 나눌 커뮤니티는 에타에 종속 | 에브리타임 | 거래·모임·시간표가 각각 다른 앱/탭으로 흩어짐 |
| P5 | 거래 상대가 같은 학교 학생인지 신뢰가 안 됨 | — | 익명 거래의 사기·노쇼 리스크 |

### 2.2 핵심 인사이트

- 대학생의 생활 반경은 **행정동이 아니라 캠퍼스**다. "동네 기반"은 캠퍼스와 어긋난다.
- **학교 이메일 인증**은 이미 대학생에게 익숙한 신뢰 장치다(에타로 학습됨).
- 거래·교재·모임·커뮤니티는 **"같은 학교 사람"이라는 하나의 신뢰 자산**을 공유한다. 앱을 나눌 이유가 없다.

## 3. 타겟 유저 & 페르소나

### 3.1 타겟

- **1차**: 국내 4년제/전문대 재학생 (자취·기숙사 비중 높은 학교 우선)
- **2차**: 졸업 예정자·대학원생·휴학생 (재학 인증 이력 보유)
- **제외**: 학교 이메일 인증 불가자 (외부인 차단이 서비스 신뢰의 핵심)

### 3.2 페르소나

**페르소나 A — "자취 새내기" 김민서 (20세, 1학년)**
- 자취방 살림을 중고로 저렴하게 채우고 싶다. 택배 대신 캠퍼스에서 직거래 선호.
- 모르는 사람과 거래가 무섭다 → "같은 학교" + "매너온도"가 안심 요소.
- 니즈: 저렴한 생활용품, 안전한 직거래, 빠른 채팅 응답.

**페르소나 B — "교재 절약러" 이준호 (23세, 3학년, 복학생)**
- 전공 교재 6권 정가 = 20만 원. 선배에게 물려받고 싶지만 아는 선배가 없다.
- 강의 시간표를 짜면서 필요한 책을 한 번에 찾고 싶다.
- 니즈: 강의명으로 교재 검색, 책 상태 사진, 되팔기.

**페르소나 C — "모임 만드는 사람" 박서연 (22세, 2학년)**
- 러닝 크루, 스터디를 직접 꾸리고 싶다. 오픈채팅은 외부인 유입이 불안.
- 니즈: 같은 학교 인증 멤버, 가입 승인제, 공지·일정 관리 도구.

## 4. 핵심 가치 제안 (Value Proposition)

| 사용자에게 주는 가치 | 이를 만드는 기능 |
|---|---|
| **믿을 수 있는 상대** | 학교 이메일 인증 필수, 매너온도, 재거래희망률, 신고/차단 |
| **캠퍼스에 최적화된 탐색** | 단과대/기숙사 위치 태그, 강의명·전공 기반 중고책, 학교별 커뮤니티 분리 |
| **하나의 앱에서 학교생활** | 거래·교재·모임·커뮤니티·시간표를 5개 탭으로 통합 |
| **직거래 친화** | 캠퍼스 내 약속장소, 약속잡기, 거래완료 → 매너 평가 흐름 |

## 5. 경쟁 서비스 비교

| 항목 | 당근마켓 | 에브리타임 | **당타** |
|---|---|---|---|
| 신뢰 기준 | 동네(GPS) | 학교 이메일 | **학교 이메일 + 캠퍼스** |
| 중고거래 | 강력 (핵심) | 장터 게시판 수준 | 당근 수준 UX + 캠퍼스 특화 |
| 중고책 | 일반 카테고리 | 책 게시판 | **강의·교수·전공 태그 기반** |
| 소모임 | 동네생활/모임 | 소모임 | 가입 승인제 + 운영도구 |
| 커뮤니티 | 동네생활 | 강력 (핵심) | 학교별 게시판 + 익명 |
| 채팅 | 강력 | 쪽지 수준 | 실시간 + 거래 연동 |
| 매너온도 | 있음 | 없음 | 있음 (거래 후 평가) |
| 시간표 | 없음 | 있음 (핵심) | 있음 + 교재 연동 |

**당타의 포지셔닝**: "당근의 거래 경험 + 에타의 학교 신뢰/학업도구" → 캠퍼스 슈퍼앱.

### 차별점 요약
1. 위치 축이 "동네"가 아니라 "학교 → 캠퍼스(단과대/기숙사)"
2. 중고책이 별도 1급 도메인 (강의 연동)
3. 시간표에서 담은 강의 → 필요한 교재 바로 탐색 (도메인 간 연결)
4. 모든 사용자가 재학 인증됨 = 커뮤니티/모임의 신뢰 기본값이 높음

## 6. 서비스 범위 (Scope)

### 6.1 v1 In Scope
- 학교 이메일 인증 회원가입 / 로그인 / 프로필
- 중고거래: 등록·탐색·찜·채팅·거래완료·끌올
- 중고책: 도서 검색·등록·강의 태그·탐색
- 소모임: 개설·가입 승인·공지·일정·모임 게시판
- 커뮤니티: 학교별 게시판·글·댓글·익명·좋아요·스크랩·핫게·투표
- 채팅: 1:1 실시간, 거래 연동, 읽음, 이미지, 약속잡기
- 매너온도: 거래 후 상호 평가, 온도 산정, 후기, 재거래희망률
- 시간표: 학기별 시간표 작성·강의 검색·공유
- 알림(인앱 + 웹푸시), 신고/차단, 통합 검색
- 관리자: 신고 처리, 사용자 정지, 대학/게시판/카테고리 관리

### 6.2 v1 Out of Scope (추후)
- 네이티브 앱 (iOS/Android) — v1은 반응형 웹앱(PWA)
- 안전결제/에스크로, 택배 연동
- 학생증 이미지 검증 (이메일 인증만)
- 강의평가(별점 리뷰) 본격 기능 — 시간표에서 링크만
- 학교 간 거래, 오픈마켓/사업자
- 추천 알고리즘(개인화 피드) — v1은 최신순/인기순
- 다국어

## 8. 사용자 여정 (핵심 시나리오)

1. **가입**: 앱 진입 → 학교 이메일 입력 → 메일함의 6자리 코드 입력 → 대학 자동 매칭 → 닉네임·프로필 → 홈
2. **첫 거래(구매자)**: 홈 피드 → 카테고리/검색 → 상품 상세 → "채팅하기" → 약속잡기 → 캠퍼스에서 직거래 → 채팅방 "거래완료" → 매너 평가
3. **첫 판매**: FAB → 사진·제목·카테고리·가격·캠퍼스 위치 → 등록 → 채팅 응대 → 예약중 → 거래완료
4. **교재 구하기**: 중고책 탭 → 강의명 "일반물리학1" 검색 → 책 상세 → 판매자와 채팅
5. **모임 가입**: 모임 탭 → "러닝 크루" → 가입 신청(한 줄 소개) → 모임장 승인 → 모임 게시판/일정 확인
6. **커뮤니티**: 커뮤니티 탭 → 자유게시판 → 글 읽기/댓글 → 익명으로 질문 글 작성 → 핫게 등극

---

## 9. 핵심 지표 (North Star & 보조지표)

- **North Star**: 주간 활성 거래(WAT) = 한 주간 "거래완료"된 건수
- 가입: 이메일 인증 시작 → 완료 전환율, 온보딩 완료율
- 거래: 상품 등록 수, 채팅 시작률(상품 조회 대비), 거래완료율, 첫 등록까지 시간
- 참여: 커뮤니티 글/댓글 수, 모임 개설·가입 수, 시간표 작성률
- 신뢰: 매너 평가 작성률, 신고 처리 SLA, 재거래희망률 평균
- 리텐션: D1/D7/D30, 학기 시작(3·9월) 시즌 스파이크

## 10. 용어 사전

| 용어 | 뜻 |
|---|---|
| 캠퍼스 | 학교 내 위치 구분 단위 (예: 공대, 중앙도서관, OO기숙사). 거래 약속 장소의 기준 |
| 매너온도 | 거래 상대에 대한 신뢰 점수. 기본 36.5℃, 평가에 따라 가감 |
| 재거래희망률 | "이 사람과 다시 거래하고 싶다" 응답 비율 |
| 끌올 | 오래된 판매글을 목록 상단으로 끌어올리기 (일정 주기 제한) |
| 핫게 | 핫게시판. 일정 시간 내 좋아요·댓글이 임계치를 넘은 글 모음 |
| 익명 | 커뮤니티 글/댓글에서 닉네임 대신 "익명" 표기 (글 단위로 익명번호 부여) |
| 도서 마스터 | ISBN 기준 표준 도서 정보 (제목/저자/정가). 개별 매물과 분리 |
| 강의 마스터 | 학교·학기·교수 기준 표준 강의 정보. 시간표·중고책 태그의 공통 참조 |
| 학기 | YYYY-(1|S|2|W) 형식. 시간표·강의의 시간 범위 |

## 11. 리스크 & 대응

| 리스크 | 대응 |
|---|---|
| 초기 매물/사용자 부족 (콜드스타트) | 1개 대학부터 집중 런칭, 학기 시작 타이밍, 학내 홍보(에타 광고/학생회 제휴) |

| 사기·노쇼 | 매너온도 하향, 신고 누적 시 자동 제한, 캠퍼스 직거래 권장 문구 |
| 에타와 정면 경쟁(커뮤니티) | 커뮤니티는 "거래·모임 유저를 붙잡는 접착제"로 포지셔닝, 무리한 확장 자제 |
| 개인정보/명예훼손 게시물 | 신고 우선순위 큐, 익명이라도 내부 로그 보관, 커뮤니티 가이드라인 |
