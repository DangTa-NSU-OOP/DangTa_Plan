# 06. 디자인 시스템 — 당타(DangTa)

> UI/UX 원칙: **당근마켓의 구조를 따르되, 캠퍼스 맥락(캠퍼스 태그·강의 태그·매너온도)을 전면에.**
> 톤: 깔끔하고 신뢰감 있는 틸/화이트. 정보 밀도는 중간, 큰 터치 타겟, 카드 리스트 중심.

---

## 1. 브랜드

- 서비스명: **당타** (DangTa) — "당근 + 에타"
- 로고: 심볼(말풍선 + 학사모 or 새싹) + 워드마크. 심볼 단독 사용 가능(파비콘/앱아이콘).
- 슬로건 후보: "우리 학교 안에서 다 되는", "캠퍼스 중고장터 + 커뮤니티"

## 3. 타이포그래피

- 폰트: **Pretendard** (본문/UI), 숫자 `tabular-nums`. 폴백: `-apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`.

| 토큰 | size / line | weight | 용도 |
|---|---|---|---|

| `title-lg` | 20 / 28 | 700 | 페이지 제목 |
| `title-md` | 17 / 24 | 600 | 섹션/상품 제목 |
| `body` | 15 / 22 | 400 | 본문 |
| `body-sm` | 13 / 18 | 400 | 메타, 보조 |

## 4. 스페이싱 · 형태

- 그리드: 4px 베이스. 화면 좌우 패딩 16px.
- 라운드: 카드 12px, 버튼 12px, 칩/뱃지 999px, 시트 상단 16px, 이미지 8px.
- 그림자: 카드 `--shadow-card`, 바텀시트 `--shadow-sheet`. 과도한 그림자 지양(당근처럼 플랫).
- 구분선: 1px `--color-border`. 리스트는 구분선 or 8px 간격 중 택1(도메인별 일관).

## 5. 레이아웃 골격

```
┌───────────────────────────────┐
│  상단 앱바 (56px)               │  ← 좌: 위치/제목, 우: 검색·알림·채팅 아이콘
├───────────────────────────────┤
│                               │
│  스크롤 영역 (콘텐츠)          │
│                               │
│                        (FAB)  │  ← 우하단, 글쓰기 (홈/중고책/커뮤니티)
├───────────────────────────────┤
│  하단 탭바 (56px + safe-area)  │  ← 홈 · 중고책 · 모임 · 커뮤니티 · 마이
└───────────────────────────────┘
```

- 최대 콘텐츠 폭 480px, 중앙 정렬(데스크톱에서도 모바일 뷰).
- 상세/글쓰기 화면은 탭바 숨김 + 뒤로가기 앱바.

## 6. 핵심 컴포넌트 규칙

### 6.1 하단 탭바 (BottomTabBar)
- 5개 고정. 아이콘 + 라벨(12px). 활성: `--color-primary-500` + 채운 아이콘. 비활성: `--color-text-sub`.
- 채팅/알림은 탭 아님(앱바). 탭바 뱃지는 안 씀(혼동 방지) — 예외: 커뮤니티 새 글 dot(선택).

### 6.2 상단 앱바 (AppBar)
- 홈: 좌측 "OO대 · 캠퍼스명" 드롭다운(캠퍼스 필터), 우측 검색·알림(dot)·채팅(count).
- 상세: 좌측 back, 중앙 타이틀(옵션), 우측 공유·더보기(⋯).

### 6.3 상품 카드 (ProductCard) — 리스트 아이템
```
┌─────┬───────────────────────────┐
│ 88x │ 제목 (2줄 말줄임)          │
│ 88  │ 캠퍼스명 · 3분 전          │
│ img │ 12,000원        [예약중]   │
│     │           ♡ 3  💬 2        │
└─────┴───────────────────────────┘
```
- 썸네일 88×88, 라운드 8px. SOLD/RESERVED는 썸네일 딤 + 배지.
- 가격 `price` 토큰. 나눔은 "나눔" 초록 텍스트.

### 6.4 중고책 카드 (BookCard)
- 표지 이미지 세로형(2:3), 우측: 도서명·저자, 강의 태그 칩, `정가 38,000` 취소선 + `15,000원` + `-61%` 빨강.

### 6.5 칩 / 필터 (Chip)
- 기본: 흰 배경 + `--color-border`. 선택: `--color-primary-50` 배경 + `--color-primary-600` 텍스트 + 테두리 primary.
- 가로 스크롤 필터 바(카테고리). 다중 필터는 바텀시트.

### 6.6 버튼 (Button)
| variant | 스타일 |
|---|---|
| primary | 배경 `--color-primary-500`, 흰 텍스트, 높이 48(주요)/40(보조) |
| secondary | 흰 배경, `--color-primary-500` 테두리+텍스트 |
| ghost | 배경 없음, 텍스트만 |
| danger | 텍스트/테두리 `--color-danger` |
- 하단 고정 CTA(상세의 "채팅하기")는 sticky 바 + 좌측 찜 하트.

### 6.7 FAB
- 56×56 원형, `--color-primary-500`, `+` 아이콘 + (스크롤 상단일 때) "글쓰기" 텍스트 확장.

### 6.8 매너온도 배지 (MannerBadge)
- `36.5℃` + 미니 게이지. 색은 §2.4 구간. 프로필/카드/채팅 헤더에 사용.

### 6.9 채팅 버블 (ChatBubble)
- 내 메시지: `--color-primary-500` 배경 흰 텍스트, 우측 정렬, 라운드 16(모서리 하나 4).
- 상대: `--color-surface` + border, 좌측. 시간/읽음은 버블 밖 작은 회색.
- 시스템 메시지: 가운데 정렬 pill (`--color-primary-50`).
- 약속 카드/가격 제안 카드: 흰 카드 + 아이콘 + 액션 버튼.

### 6.10 바텀시트 (Sheet)
- 필터, 상태 변경, 더보기 메뉴, 신고 사유 선택 등에 일관 사용. 드래그 핸들 + 딤 배경.

### 6.11 빈 상태 / 로딩
- 빈 상태: 일러스트(단색 라인) + 한 줄 안내 + 액션 버튼("첫 상품 올리기").
- 로딩: 스켈레톤(카드 형태). 스피너 최소화.

### 6.12 시간표 그리드 (TimetableGrid)
- 세로 요일(월~금 기본, 주말 토글), 가로 시간(09~18시 기본, 확장). 강의 블록은 파스텔 컬러셋(10색), 텍스트는 진하게.

---

## 7. 아이콘 · 이미지

- 아이콘: Lucide (선형, 24px 기준, stroke 1.75). 활성 탭만 채움 스타일.
- 이미지 비율: 상품 1:1, 책 표지 2:3, 커뮤니티 첨부 자유(썸네일 크롭 4:3).
- 플레이스홀더: `--color-primary-50` 바탕 + 서비스 심볼.

---

## 8. 당근 대비 — 계승 / 차별

| 당근에서 계승 | 당타에서 바꾸는 것 |
|---|---|
| 카드형 피드 + 썸네일 좌측 레이아웃 | 위치 라벨을 "동" → "캠퍼스(단과대/기숙사)" |
| 매너온도, 거래 후 평가 흐름 | 평가에 "재거래희망률" 노출 강화 |
| 채팅 중심 거래, 하단 고정 CTA | 채팅에 "약속 장소 = 캠퍼스 위치" 프리셋 |
| FAB 글쓰기, 카테고리 필터 | 중고책은 별도 탭 + 강의 태그 필터 |
| 동네생활(커뮤니티) | 학교별 게시판 + 익명번호 + 핫게(에타식) |
| 오렌지 브랜드 | 틸(#0EA5A4) 브랜드 — 시각적 차별화 |

---

## 9. 접근성 체크리스트
- 텍스트 대비 4.5:1 이상 (primary-500 위 흰 텍스트 OK).
- 터치 타겟 최소 44×44.
- 폼 인풋 라벨/에러 텍스트 명시, 아이콘 버튼 `aria-label`.
- 색만으로 상태 전달 금지 → 배지 텍스트 병행("예약중").
- 모션 최소화 설정 존중(`prefers-reduced-motion`).
