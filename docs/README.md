## 와이어프레임

별도 비주얼 디자인 캔버스(Artifact)로 제공 — 16개 화면 목업(모바일). 링크는 대화에서 전달.

## 기술 스택

- **Frontend**: Next.js(App Router), React, TypeScript, TanStack Query, Zustand, Tailwind, PWA
- **Backend**: Spring Boot 3, Spring Security, Spring Data JPA, WebSocket(STOMP)
- **DB/Infra**: PostgreSQL, Redis, S3(+CDN), 이메일 발송(SES), Web Push(VAPID)

## 핵심 결정 사항

| 항목 | 결정 |
|---|---|
| 위치 기준 | 학교 → 캠퍼스(단과대/기숙사) — "동네"가 아님 |
| 인증 | 학교 이메일 인증코드(6자리). 미인증 시 읽기도 불가 |
| v1 범위 | 전체 도메인 포함, 1개 대학 파일럿 |
| 브랜드 컬러 | Teal `#0EA5A4` + White |
| 콘텐츠 스코프 | 작성자 대학에 귀속, 기본 노출 = 같은 대학 |

## 문서 운용 규칙

- 기능은 **ID**(예: `PROD-6`)로 식별하고 이슈 트래커 라벨과 1:1 매칭.
- 구현 중 스펙이 바뀌면 **문서를 먼저 갱신**한다(문서 = source of truth).
- 각 마일스톤 종료 시 02/03/04 문서와 구현 diff 리뷰.
